Case Studies

Selected Case Studies

How I approach real digital marketing problems — from research to learning.

🔍 SEO Audit

Problem Website had weak on-page SEO, missing meta descriptions and internal linking gaps.
Research Ran a crawl using Screaming Frog, checked Search Console and reviewed top competitors.
Strategy Prioritized title/meta fixes, header hierarchy, internal linking and schema markup.
Implementation Optimized pages via Rank Math, added schema and improved internal links.
Learning Technical SEO foundations strongly influence on-page performance and user experience.

🔑 Keyword Research

Problem Needed a keyword strategy for a niche content blog.
Research Used Semrush and Keyword Planner to find low-competition, high-intent keywords.
Strategy Grouped keywords by search intent and mapped them to content pages.
Implementation Created a practical content plan in Google Sheets with priorities.
Learning Search intent alignment is critical — high-volume keywords are not always the right target.

📍 Local SEO

Problem Local business website lacked local SEO signals.
Research Analyzed Google Business Profile, local competitors and citation gaps.
Strategy Optimize NAP consistency, local keywords, service pages and LocalBusiness schema.
Implementation Updated pages with location keywords, added schema and improved service structure.
Learning Consistent NAP and structured data are foundational for local search visibility.

⚡ Website Optimization

Problem Website had slow loading, unoptimized images and layout issues.
Research Checked PageSpeed Insights, Core Web Vitals and image weights.
Strategy Compress images, enable caching, simplify CSS/JS, improve mobile layout.
Implementation Used TinyPNG, WordPress caching plugin and simplified content sections.
Learning Performance directly affects SEO, UX and conversions.

📊 Analytics & Search Console

Problem No tracking was set up for organic performance.
Research Reviewed existing pages, indexed URLs and search queries.
Strategy Install GA4 + Search Console, verify site, submit sitemap, monitor performance.
Implementation Set up tracking, connected GSC, reviewed top queries and impressions.
Learning Data-driven SEO decisions require clean tracking from day one.

📝 Content Strategy

Problem Content was inconsistent and not aligned with search intent.
Research Analyzed top-performing content, competitor topics and buyer personas.
Strategy Built a content calendar with topics, formats and target keywords.
Implementation Created blog briefs, Canva visuals and social media post ideas.
Learning Content performs best when strategy, SEO and creativity align.
